로그인 가이드

서버 종료 → 로그인 → 재시작 순서로 진행 (펼치기)
  1. 실행 중인 muse-gui 서버를 종료합니다 (터미널 Ctrl+C 또는 kill).
  2. 터미널에서 muse login을 실행하고 브라우저 승인으로 로그인합니다.
  3. 서버를 다시 시작합니다.
  4. 설정 > 계정에서 이름·이메일이 표시되는지 확인합니다.
  5. 로그아웃은 muse logout — 자격이 삭제되므로 필요할 때만 실행하세요.

로그인·로그아웃은 터미널에서만 가능합니다 (브라우저 승인 / 자격 삭제).
