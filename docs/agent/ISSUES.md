## 진행 중

- 없음.

## 해결됨

- 2026-11-26 구버전 JS 고착: `?v=` 핀이 서버 시작 시점에 고정되어
  VERSION을 올려도 재시작 전까지 구 코드가 서빙됐다.
  대응: `Cache-Control: no-cache` 추가로 매 로드마다 재검증.
  그래도 안 되면 강력 새로고침(Ctrl+Shift+R).
- 2026-11-26 localStorage 할당량 초과 시 대화 소실:
  저장 실패 경로가 인메모리 목록을 `pop()`해서 현재 대화를 증발시켰다.
  대응: 슬림 저장 + 1회 경고, 메모리 불변으로 수정.
- 2026-11-26 딥링크 입수 레이스: 부팅 시 비동기 입수가 사용자 이동 후
  도착해 화면을 가로채 새 세션으로 옮겼다.
  대응: `convKey`·채팅 내용·명시적 새 대화 여부를 확인 후 입수.
- 2026-11-26 BASE_DIR 밖 경로 접근 시도: 화이트리스트는
  `static/{js,css}/[A-Za-z0-9_-]+.(js|css)`만 허용한다.
  `..`·절대경로·다른 확장자는 404로 떨어진다.
